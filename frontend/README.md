# Frontend Folder

This folder is reserved for the web front end for Relishing Roots.

Suggested options:
- React + Vite
- Vue 3 + Vite
- Blade templates if you want a Laravel-only UI
- Tailwind CSS for styling

Start by creating a UI for:
- home feed
- recipe cards
- add recipe form
- favorites and archive
- profile page

The backend API will live in the Laravel app under `backend/`.
